# Japanese Pop-Tech Wordmark Style System

## Source Analysis

This system was distilled from 79 reference images in the project `logo/` folder. The dominant family is playful Japanese display typography for developer tools, programming concepts, and internet culture—not anime character illustration.

## Core DNA

### 1. Letter construction

- Build the Latin name from chunky, hand-shaped display letters.
- Vary width, height, baseline, and rotation slightly while preserving the reading order.
- Favor rounded corners, bulbous terminals, oversized counters, and compact kerning.
- Let one or two letters become visual anchors; do not distort every letter equally.
- Use case changes deliberately to create rhythm, not according to normal typesetting alone.

### 2. Japanese layer

- Place kana like furigana above, below, or inside the gaps of the Latin wordmark.
- Keep kana secondary at about 10–20% of the main letter height.
- Use short interjections, pronunciation guides, or playful labels only when linguistically sound.
- Angle or arc the kana slightly to follow the wordmark rhythm.

### 3. Tech layer

- Integrate one to three semantically relevant micro-symbols: `</>`, braces, terminal cursor, gear, cube, cloud, waveform, bolt, package, command prompt, or a simple original mascot head.
- Embed symbols into counters, dots, crossbars, underlines, and letter endings.
- Prefer icon-letter fusion over icons floating beside the name.
- Keep code fragments short enough to read: one token or one compact expression.

### 4. Outline and depth

- Use a white keyline to separate the mark from any background.
- Add a dark gray or near-black offset extrusion down and right.
- Keep shadow direction consistent and its width roughly 4–8% of the main letter height.
- Use at most one internal highlight or second shallow offset layer.

### 5. Color

- Use 2–4 flat brand-derived hues.
- Let one dominant hue carry 50–70% of colored area, one secondary hue carry 20–35%, and one accent carry under 15%.
- Use near-black for monochrome or error-message concepts.
- Reserve bright accent colors for punctuation, one syllable, or the integrated icon.
- Avoid continuous gradients unless the brief explicitly requires one; if used, confine it to a single letter group.

### 6. Composition

- Default canvas: horizontal 16:9 or 3:2, with the logo occupying a compact central area.
- Default logo silhouette: roughly 1.7:1 to 2.6:1.
- Layer the mark as: hero wordmark → kana rhythm → icon pun → tiny supporting copy.
- Use an angled underline, banner, or long terminal-like stroke to close the bottom edge.
- Keep 8–12% clear padding around the complete shadow silhouette.

## Composition Archetypes

### A. Compact sticker

One word, tight irregular letter block, white keyline, dark offset shadow, one tiny kana label. Best for short brands of 3–7 letters.

### B. Wide developer badge

Primary wordmark across the canvas, small code token below, icon integrated at left or right, kana following the baseline. Best for tools and frameworks.

### C. Stacked exclamation

Two short words on staggered rows with oversized punctuation and diagonal energy. Best for errors, slogans, or expressive community brands.

### D. Symbol-led wordplay

A distinct original symbol replaces part of one letter, while the rest of the wordmark stays simple. Best when the product has a clear metaphor.

## Personality Axes

Choose one primary axis and one supporting axis:

- cute ↔ assertive
- clean ↔ chaotic
- rounded ↔ angular
- monochrome ↔ candy-color
- friendly ↔ technical

Do not max out both ends or all axes. Contrast creates character: for example, rounded + technical, or monochrome + cute.

## Text Hierarchy Limits

- Level 1: exact brand name, one occurrence, 65–80% of attention.
- Level 2: kana pronunciation or short expressive phrase, 10–20%.
- Level 3: one tagline/code token, 5–10%.
- Micro-text below 5% should be omitted rather than rendered illegibly.

## Originality Transform

When a reference feels too close, change at least four of these six dimensions:

1. outer silhouette
2. word stacking and baseline
3. letter construction
4. icon metaphor
5. palette distribution
6. kana/tagline placement

Never use an existing brand's exact symbol as the integrated icon unless the user owns it and explicitly supplies it for brand-preserving work.
