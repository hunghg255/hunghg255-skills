## Usage Instructions

### Referencing During Phase 3 Recommendations
After recommending a design direction, showcase the pre-made screenshot for the corresponding scenario:
```
"This is what the Pentagram style looks like for a WeChat cover → [show cover/cover-pentagram.png]"
"The Takram style for a PPT data slide feels like this → [show ppt/ppt-takram.png]"
```

### Scenario Matching Priority
1. Exact match for user's scenario → Show the corresponding scenario directly
2. No exact match but similar type → Show the closest scenario (e.g., "product website" → show SaaS landing page)
3. No match at all → Skip pre-made samples, proceed directly to Phase 3.5 live generation

### Side-by-Side Comparison Display
The 3 styles for the same scenario are suitable for side-by-side display, helping users visually compare:
- "This is the same WeChat cover, implemented in 3 different styles"
- Display order: Pentagram (rational restraint) → Build (luxury minimal) → Takram (soft warm)
